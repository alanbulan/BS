#### 2.1 业务需求分析 （1000字）

- **2.1.1 用户角色分析**
  
  **表2-1 系统用户角色划分**
  
  | 角色类型 | 使用终端 | 权限级别 | 主要功能 | 实际用户数 |
  |---------|---------|---------|----------|-----------|
  | 系统管理员 | **Web管理端** | admin | 系统配置、用户管理、数据审核 | 2人 |
  | 应急管理员 | **Web管理端** | expert | 风险评估、预警发布、监测管理 | 4人 |
  | 监测人员 | **Web管理端** | user(高级) | 监测站维护、数据录入 | 6人 |
  | **普通公众** | **移动端App** | user | **查看预警、上报灾害、导航避险** | **不限** |
  
  **说明**：
  - **Web管理端**：专业人员使用，提供完整的管理和分析功能，需要账号登录
  - **移动端App**：普通公众使用，注册即可，重点提供预警和避险服务
  
- **2.1.2 业务场景分析**
  
  **场景1：管理员日常监测（Web端）**
  - 查看20个监测站实时数据
  - 查看ECharts可视化图表
  - 管理监测站点和配置
  
  **场景2：管理员风险评估（Web端）**
  - 选择风险区域
  - 点击"评估"按钮
  - ML模型自动计算（<3秒）
  - 查看雷达图、环形图等可视化结果
  - 发布预警（如果高风险）
  
  **场景3：公众紧急避险（移动端）**
  - 接收预警推送
  - 查看附近风险区域
  - 搜索最近避难所
  - GPS导航到避难所
  
  **场景4：公众灾害上报（移动端）**
  - 拍照上传灾害现场
  - GPS自动定位
  - 填写描述信息
  - 提交到系统（管理员审核）

- **5.3.2 A*算法实现**（517行代码）
  ```typescript
  // AStarPathfinder.ts 核心逻辑
  class AStarPathfinder {
    findPath(起点, 终点) {
      openSet = {起点}
      closedSet = {}
      
      while (openSet不为空) {
        current = openSet中f值最小的节点
        if (current == 终点) 返回路径
        
        for (邻居节点 of current.neighbors) {
          计算g = current.g + 距离
          计算h = 直线距离到终点
          计算风险因子
          更新节点
        }
      }
    }
  }
  ```
