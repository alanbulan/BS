## 🔧 转换方法（推荐）

### 方法1：使用Pandoc（最佳）

**步骤1：安装Pandoc**
```bash
# 下载地址：https://pandoc.org/installing.html
# Windows下载安装包直接安装
```

**步骤2：准备Word模板**
- 下载学校的毕业论文Word模板
- 另存为`毕设模板.docx`

**步骤3：转换命令**
```bash
cd D:\BS\disaster-risk-system\docs\毕设

# 合并所有章节
type 01-绪论.md 02-需求分析.md 03-系统总体设计.md 04-数据库设计.md 05-核心功能实现.md 06-系统测试.md 07-总结与展望.md 参考文献-完整版.md > 完整论文-合并.md

# 转换为Word
pandoc 完整论文-合并.md -o 毕业论文初稿.docx --reference-doc=毕设模板.docx
```

## 📐 格式要求（标准毕业论文）

### 页面设置
- 纸张：A4（210mm×297mm）
- 页边距：上下2.54cm，左右3.17cm
- 页眉：1.5cm
- 页脚：1.75cm

### 字体字号
- 标题1（章标题）：黑体三号加粗，段前24磅段后18磅
- 标题2（节标题）：黑体四号加粗，段前18磅段后12磅
- 标题3（小节标题）：黑体小四号加粗，段前12磅段后6磅
- 正文：宋体小四号，行距1.5倍，首行缩进2字符
- 图表标题：宋体五号居中
- 代码：Consolas 9号，底色灰色

### 图表格式
- 图题：图3-1 系统总体架构图（图号-标题，黑体五号居中）
- 图注：图片下方，宋体五号，300字以内
- 表题：表4-1 monitoring_stations表结构（表号-标题，黑体五号居中）
- 表格：三线表（顶线、底线1.5磅，中线0.75磅）

### 页眉页脚
- 页眉：XX大学本科毕业论文（居中，宋体小五号）
- 页脚：页码（居中，Times New Roman小五号）
- 摘要、目录用罗马数字（I, II, III）
- 正文用阿拉伯数字（1, 2, 3）

## 📊 表格格式调整

### Markdown表格转Word三线表

**原始Markdown表格**：
```markdown
| 字段名 | 数据类型 | 说明 |
|--------|---------|------|
| id | INTEGER | 主键 |
```

**Word中调整**：
1. 粘贴后选中表格
2. 表格工具 → 设计 → 边框：只保留顶线、标题行底线、表格底线
3. 线条粗细：顶线和底线1.5磅，中线0.75磅
4. 字体：表头黑体小四，表体宋体五号
5. 对齐：文字左对齐，数字右对齐

---

## 💻 代码格式调整

**代码块统一格式**：
- 字体：Consolas或Courier New
- 字号：9号
- 行距：单倍
- 底色：RGB(245, 245, 245)
- 边框：0.5磅灰色实线

**Word中设置**：
1. 选中代码段
2. 段落 → 缩进：左缩进1cm
3. 格式 → 字体：Consolas 9号
4. 格式 → 边框和底纹 → 底纹：灰色5%
5. 格式 → 边框：外边框0.5磅
