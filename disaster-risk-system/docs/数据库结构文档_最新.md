## 视图定义

### 1. v_current_risk_status (当前风险状态视图)
显示各风险区域的最新风险评估状态
```sql
CREATE VIEW v_current_risk_status AS
SELECT 
    rz.name as zone_name,
    rz.code as zone_code,
    dt.name as disaster_type,
    ra.current_risk_level,
    ra.predicted_risk_24h,
    ra.confidence_score,
    ra.assessment_time
FROM risk_zones rz
JOIN risk_assessments ra ON rz.id = ra.zone_id
JOIN disaster_types dt ON rz.disaster_type_id = dt.id
WHERE ra.assessment_time = (
    SELECT MAX(assessment_time) 
    FROM risk_assessments ra2 
    WHERE ra2.zone_id = ra.zone_id
);
```

### 2. v_active_warnings (活跃预警视图)
显示当前有效的预警信息
```sql
CREATE VIEW v_active_warnings AS
SELECT 
    w.warning_id,
    w.title,
    w.warning_level,
    rz.name as zone_name,
    dt.name as disaster_type,
    w.issue_time,
    w.expiry_time,
    w.status
FROM warnings w
JOIN risk_zones rz ON w.zone_id = rz.id
JOIN disaster_types dt ON w.disaster_type_id = dt.id
WHERE w.status = 'active' AND w.expiry_time > NOW();
```

### 3. v_shelter_capacity (避难场所容量视图)
显示避难场所的容量使用情况
```sql
CREATE VIEW v_shelter_capacity AS
SELECT 
    s.name,
    s.capacity,
    s.current_occupancy,
    (s.capacity - s.current_occupancy) as available_capacity,
    ROUND((s.current_occupancy::float / s.capacity * 100)::numeric, 2) as occupancy_rate,
    s.shelter_type,
    s.safety_level
FROM shelters s
WHERE s.is_active = true;
```

## 触发器函数

### update_updated_at_column()
自动更新记录的updated_at字段
```sql
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = CURRENT_TIMESTAMP;
    RETURN NEW;
END;
$$ language 'plpgsql';
```

## 重要说明

1. **空间数据**: 所有几何字段使用WGS84坐标系(SRID: 4326)
2. **时间字段**: 统一使用TIMESTAMP WITHOUT TIME ZONE
3. **JSON字段**: 使用JSONB类型以获得更好的性能
4. **索引策略**: 空间字段使用GIST索引，时间字段使用BTREE索引
5. **外键约束**: 确保数据完整性
6. **触发器**: 自动维护updated_at字段
7. **视图**: 提供常用查询的便捷访问

此文档与实际数据库结构完全一致，可作为前后端开发的权威参考。
