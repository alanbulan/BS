## 数据库特性说明

### PostGIS 扩展

本数据库使用 PostGIS 扩展支持地理空间数据：

- **GEOMETRY(Point,4326)**: 点坐标（WGS84）
- **GEOMETRY(LineString,4326)**: 线串（用于路径）
- **GEOMETRY(Polygon,4326)**: 多边形（用于区域）

### 主要功能

1. **用户管理**: 支持多角色用户系统（普通用户、专家、管理员）
2. **监测系统**: 实时监测站数据采集和存储
3. **风险评估**: 基于监测数据的智能风险评估
4. **预警发布**: 多级预警信息发布和管理
5. **避难管理**: 避难场所信息和占用情况管理
6. **路径规划**: 基于道路网络的逃生路线规划
7. **用户报告**: 公众参与的灾害信息上报

### 数据关系

```
users (用户)
  ├─> user_reports (用户报告)
  ├─> risk_assessments (风险评估)
  ├─> refresh_tokens (令牌)
  └─> password_reset_tokens (重置令牌)

disaster_types (灾害类型)
  ├─> risk_zones (风险区域)
  ├─> warnings (预警)
  └─> user_reports (用户报告)

risk_zones (风险区域)
  ├─> monitoring_stations (监测站)
  ├─> risk_assessments (风险评估)
  └─> warnings (预警)

monitoring_stations (监测站)
  └─> monitoring_data (监测数据)

shelters (避难所)
  └─> shelters_occupancy_history (占用历史)
```

## 19. v_active_warnings - 活跃预警视图

**视图名**: `v_active_warnings`  
**说明**: 查询当前活跃且未过期的预警信息

### 字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|

| expiry_time | TIMESTAMP | 过期时间 |
| status | VARCHAR(20) | 状态 |

### 视图定义

```sql
SELECT 
  w.warning_id,
  w.title,
  w.warning_level,
  rz.name AS zone_name,
  dt.name AS disaster_type,
  w.issue_time,
  w.expiry_time,
  w.status
FROM warnings w
JOIN risk_zones rz ON w.zone_id = rz.id
JOIN disaster_types dt ON w.disaster_type_id = dt.id
WHERE w.status = 'active' 
  AND w.expiry_time > NOW();
```

| disaster_type | VARCHAR(50) | 灾害类型 |
| current_risk_level | INTEGER | 当前风险等级 |
| predicted_risk_24h | INTEGER | 24小时预测风险等级 |
| confidence_score | DOUBLE PRECISION | 置信度分数 |
| assessment_time | TIMESTAMP | 评估时间 |

### 视图定义

```sql
SELECT 
  rz.name AS zone_name,
  rz.code AS zone_code,
  dt.name AS disaster_type,
  ra.current_risk_level,
  ra.predicted_risk_24h,
  ra.confidence_score,
  ra.assessment_time
FROM risk_zones rz
JOIN risk_assessments ra ON rz.id = ra.zone_id
JOIN disaster_types dt ON rz.disaster_type_id = dt.id
WHERE ra.assessment_time = (
  SELECT MAX(ra2.assessment_time)
  FROM risk_assessments ra2
  WHERE ra2.zone_id = ra.zone_id
);
```

## 21. v_shelter_capacity - 避难所容量视图

**视图名**: `v_shelter_capacity`  
**说明**: 实时查看活跃避难所的容量和占用情况

### 字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| name | VARCHAR(100) | 避难所名称 |
| capacity | INTEGER | 总容量 |
| current_occupancy | INTEGER | 当前占用 |
| available_capacity | INTEGER | 可用容量 |
| occupancy_rate | NUMERIC(5,2) | 占用率(%) |
| shelter_type | VARCHAR(50) | 避难所类型 |
| safety_level | INTEGER | 安全等级 |

### 视图定义

```sql
SELECT 
  name,
  capacity,
  current_occupancy,
  capacity - current_occupancy AS available_capacity,
  (current_occupancy::DOUBLE PRECISION / capacity::DOUBLE PRECISION * 100)::NUMERIC(5,2) AS occupancy_rate,
  shelter_type,
  safety_level
FROM shelters
WHERE is_active = true;
```

SELECT DISTINCT ON (soh.shelter_id)
  soh.id,
  soh.shelter_id,
