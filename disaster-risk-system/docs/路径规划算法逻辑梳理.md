```sql
-- 示例：生成环形道路
CREATE OR REPLACE FUNCTION generate_ring_road(
  center_lng FLOAT,
  center_lat FLOAT,
  radius_km FLOAT,
  points_count INT,
  road_name VARCHAR
) RETURNS VOID AS $$
DECLARE
  i INT;
  angle FLOAT;
  coords TEXT[];
BEGIN
  coords := ARRAY[]::TEXT[];
  
  FOR i IN 0..points_count LOOP
    angle := (i::FLOAT / points_count) * 2 * PI();
    coords := array_append(coords, 
      (center_lng + radius_km * COS(angle) / 111.32) || ' ' ||
      (center_lat + radius_km * SIN(angle) / 111.32)
    );
  END LOOP;
  
  INSERT INTO road_network (
    road_id, name, geometry, road_type
  ) VALUES (
    'RING_' || road_name,
    road_name,
    ST_GeomFromText('LINESTRING(' || array_to_string(coords, ',') || ')', 4326),
    '环路'
  );
END;
$$ LANGUAGE plpgsql;

-- 生成北京环路
SELECT generate_ring_road(116.4074, 39.9042, 5, 100, '三环路');
SELECT generate_ring_road(116.4074, 39.9042, 8, 120, '四环路');
```

## 📈 性能影响分析

### A*算法的前提条件

```
1. 路网图 (Graph)
   ├─ 节点 (Nodes): 道路交叉点
   └─ 边 (Edges): 道路段
   
2. 最小数据要求
   ├─ 覆盖区域的道路网格
   ├─ 至少形成连通图
   └─ 起点和终点可达任意节点
   
3. 理想数据密度
   ├─ 城市中心: 200-500米一个节点
   ├─ 郊区: 500-1000米一个节点
   └─ 高速公路: 1-2公里一个节点
```

### 如果没有道路数据

**A*算法直接失效：**
```
graph.size === 0 → 无法运行
pathfinder.findPath() → 返回null
```

**系统不会崩溃**，会自动：
```
降级到直线路径 (createDirectRoute)
  ├─ 2点LineString
  ├─ 直线距离 × 1.3 (考虑绕行)
  └─ 基本可用，但不智能
```
