# 智能化地质灾害风险评估与逃生路径规划系统

**项目状态**: 🟢 核心功能已完成，系统可本地运行  
**最后更新**: 2025-10-09  
**版本**: v1.2.0 ✨ 智能导航版

## 项目概述
基于多源地理数据融合的智能化地质灾害风险评估系统，结合实时气象数据和地质监测数据，为用户提供动态风险评估、最优逃生路径规划和AR导航功能。

## 核心创新点
1. ✅ **多维度风险评估模型**：融合地形、地质、气象、人口密度等多源数据
2. ✅ **动态风险预测**：基于机器学习的时空风险预测模型
3. ✅ **智能路径规划**：A*算法 + 35,506条真实道路 + 风险区域避让 ✨今日完成
4. ✅ **实时GPS导航**：沿路导航指令 + 偏离检测 + 自动重规划 ✨今日完成
5. ✅ **众包数据收集**：用户上报实时灾害信息 + 图片上传 + 投票功能
6. 🔄 **AR实景导航**：现实场景叠加逃生指引信息（规划中）

### 关键表结构示例

#### 1. users - 用户表
- 基本信息：username, email, phone, password_hash
- 位置信息：location (GEOMETRY Point)
- 扩展信息：full_name, department, position
- 权限管理：role (user/admin/expert), permissions (JSONB)
- 审计字段：created_at, updated_at, last_login

#### 2. monitoring_data - 监测数据表
- 支持多种数据类型：temperature, humidity, pressure, rainfall, wind_speed等
- 自动生成服务：每5分钟为8个活跃站点生成40条数据
- 空间索引：location (GEOMETRY Point)
- 数据质量：quality_flag字段

#### 3. risk_zones - 风险区域表
- 空间数据：geometry (GEOMETRY Polygon)
- 风险评估：base_risk_level, current_risk_level
- 地理特征：area_sqkm, population_density, elevation_avg, slope_avg
- 关联关系：disaster_type_id外键

#### 4. warnings - 预警信息表
- 预警级别：warning_level (蓝色/黄色/橙色/红色)
- 空间范围：affected_area (GEOMETRY Polygon)
- 时间管理：issued_at, expires_at, is_active
- 内容：title, description, instructions
