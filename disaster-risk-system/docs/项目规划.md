# 智能化地质灾害风险评估与逃生路径规划系统

## 项目概述
基于多源地理数据融合的智能化地质灾害风险评估系统，结合实时气象数据和地质监测数据，为用户提供动态风险评估、最优逃生路径规划和AR导航功能。

## 核心创新点
1. **多维度风险评估模型**：融合地形、地质、气象、人口密度等多源数据
2. **动态风险预测**：基于机器学习的时空风险预测模型
3. **智能路径规划**：考虑实时路况和灾害影响的最优逃生路径
4. **AR实景导航**：现实场景叠加逃生指引信息
5. **众包数据收集**：用户上报实时灾害信息

## 技术架构

### 前端技术栈
- **移动端**：React Native + TypeScript
- **Web管理端**：Vue3 + TypeScript + Element Plus
- **地图引擎**：Leaflet
- **3D可视化**：Three.js + Cesium.js
- **AR功能**：AR.js / React Native AR

### 后端技术栈
- **API服务**：Node.js + Express.js + TypeScript
- **数据库**：PostgreSQL + PostGIS（空间数据）
- **缓存**：Redis（实时数据缓存）
- **消息队列**：RabbitMQ（异步任务处理）
- **机器学习**：Python + TensorFlow/PyTorch

### 数据源
- **地形数据**：SRTM DEM数据
- **地质数据**：地质调查局公开数据
- **气象数据**：气象局API接口
- **道路网络**：OpenStreetMap数据
- **人口数据**：统计局人口普查数据

## 数据库设计

### 核心数据表结构

#### 1. 用户表 (users)
```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    phone VARCHAR(20),
    password_hash VARCHAR(255) NOT NULL,
    location GEOMETRY(POINT, 4326), -- 用户当前位置
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 2. 地质灾害类型表 (disaster_types)
```sql
CREATE TABLE disaster_types (
    id SERIAL PRIMARY KEY,
    name VARCHAR(50) NOT NULL, -- 滑坡、泥石流、地震等
    description TEXT,
    risk_level INTEGER CHECK (risk_level BETWEEN 1 AND 5),
    warning_threshold JSONB -- 预警阈值参数
);
```

#### 3. 风险区域表 (risk_zones)
```sql
CREATE TABLE risk_zones (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    geometry GEOMETRY(POLYGON, 4326), -- 风险区域边界
    disaster_type_id INTEGER REFERENCES disaster_types(id),
    base_risk_level INTEGER CHECK (base_risk_level BETWEEN 1 AND 5),
    population_density FLOAT,
    elevation_avg FLOAT,
    slope_avg FLOAT,
    geological_structure JSONB, -- 地质结构信息
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 4. 实时监测数据表 (monitoring_data)
```sql
CREATE TABLE monitoring_data (
    id SERIAL PRIMARY KEY,
    station_id VARCHAR(50) NOT NULL,
    location GEOMETRY(POINT, 4326),
    data_type VARCHAR(50) NOT NULL, -- rainfall, groundwater, slope_displacement等
    value FLOAT NOT NULL,
    unit VARCHAR(20),
    timestamp TIMESTAMP NOT NULL,
    quality_flag INTEGER DEFAULT 1 -- 数据质量标识
);
```

#### 5. 风险评估结果表 (risk_assessments)
```sql
CREATE TABLE risk_assessments (
    id SERIAL PRIMARY KEY,
    zone_id INTEGER REFERENCES risk_zones(id),
    assessment_time TIMESTAMP NOT NULL,
    current_risk_level INTEGER CHECK (current_risk_level BETWEEN 1 AND 5),
    predicted_risk_24h INTEGER CHECK (predicted_risk_24h BETWEEN 1 AND 5),
    predicted_risk_72h INTEGER CHECK (predicted_risk_72h BETWEEN 1 AND 5),
    contributing_factors JSONB, -- 影响因素权重
    confidence_score FLOAT CHECK (confidence_score BETWEEN 0 AND 1)
);
```

#### 6. 避难场所表 (shelters)
```sql
CREATE TABLE shelters (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    location GEOMETRY(POINT, 4326),
    capacity INTEGER NOT NULL,
    current_occupancy INTEGER DEFAULT 0,
    shelter_type VARCHAR(50), -- 临时、永久、医疗等
    facilities JSONB, -- 设施信息
    contact_info JSONB,
    is_active BOOLEAN DEFAULT true
);
```

#### 7. 逃生路径表 (escape_routes)
```sql
CREATE TABLE escape_routes (
    id SERIAL PRIMARY KEY,
    start_point GEOMETRY(POINT, 4326),
    end_point GEOMETRY(POINT, 4326),
    route_geometry GEOMETRY(LINESTRING, 4326),
    distance_meters FLOAT,
    estimated_time_minutes INTEGER,
    difficulty_level INTEGER CHECK (difficulty_level BETWEEN 1 AND 5),
    route_conditions JSONB, -- 路况信息
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 8. 用户上报信息表 (user_reports)
```sql
CREATE TABLE user_reports (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id),
    location GEOMETRY(POINT, 4326),
    report_type VARCHAR(50) NOT NULL, -- 灾害类型或路况
    description TEXT,
    severity INTEGER CHECK (severity BETWEEN 1 AND 5),
    images JSONB, -- 图片URL数组
    verification_status VARCHAR(20) DEFAULT 'pending',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
